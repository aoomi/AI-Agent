# 开发指南

## 固定流程

1. 读取项目记忆、项目沟通基线和任务对应规范。
2. 确认产品决定、目录归属、命名及共享契约。
3. 建立最小可回退变更和测试。
4. 实现后执行静态检查、构建、测试和真实入口验证。
5. 同步项目记忆、变更记录和唯一职责文档。

## 分层开发

- 前端页面只消费标准 Store/服务，不直接请求或写业务数据。
- 平台底座不依赖业务插件。
- 插件只通过契约、事件和授权能力访问平台。
- 适配器封装 LangGraph、Dify、ComfyUI 和模型提供方差异。

## 当前限制

新平台要求 Python 3.11 及以上版本。根目录 `pyproject.toml` 是 Python 安装与测试依赖入口；安装项目后使用 `ai-agent-api` 启动平台进程，默认监听 `127.0.0.1:8080`，运行健康检查为 `GET /health`。可通过 `AI_AGENT_HOST`、`AI_AGENT_PORT` 和 `AI_AGENT_ENVIRONMENT` 覆盖进程配置。前端按根目录 README 安装依赖后开发。
