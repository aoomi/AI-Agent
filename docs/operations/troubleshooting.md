# 故障排查

按健康检查、身份与租户、任务状态、依赖服务、模型提供方、对象存储、数据库、前端网络的顺序排查。

| 现象 | 首要检查 | 禁止操作 |
|---|---|---|
| 请求失败 | API 健康、关联 ID、服务端错误码 | 用客户端伪造成功状态 |
| 任务长期运行 | 截止时间、取消信号、执行器心跳 | 无期限等待或重复提交 |
| 切换项目串数据 | 完整身份键、会话令牌、项目缓存 | 复用全局业务状态 |
| 媒体打不开 | 文件存在、大小、哈希、编码和权限 | 覆盖原始母版 |
| 插件不可用 | 签名、版本、权限和依赖分类 | 绕过插件校验直接加载 |

排障记录必须包含时间、环境、租户、项目、关联 ID、影响范围、操作和恢复结果，敏感字段需脱敏。
