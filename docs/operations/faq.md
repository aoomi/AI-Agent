# 常见问题

## 当前项目可以直接生产部署吗？

不可以。平台 API、契约、任务、系统 AI 和短剧插件已有可运行基线，但生产提供方、部署编排、持久化、安全沙箱和灾备尚未验收。

## 业务逻辑应该写在哪里？

写入 `plugins/{builtin|custom}/`；`.kernel/` 与 `platform/` 禁止行业业务逻辑。

## LangGraph、Dify、ComfyUI 谁是平台大脑？

LangGraph 是规划中的可恢复编排大脑；模型负责推理；Dify 与 ComfyUI 是可替换能力提供方。当前仍使用自研调度器，LangGraph 适配尚未完成。

## 文档冲突时以什么为准？

按 `README.md` 的文档读取顺序和每类唯一来源执行，发现冲突先停止开发并修正文档。
