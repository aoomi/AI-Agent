# AI短剧从剧本到成片全链路标准化规范

版本：2026-08-10｜本文件优先于旧生产参数｜规范验收目标

执行状态：本文件同时包含已实现基线和待开发验收条款。未在运行时能力清单中验证通过的条款不得宣称已实现，调用方必须返回`capability_not_implemented`并停止推进，不得用提示词模拟代码能力。当前待开发项包括：角色无服装基础体、服装GLB装配、Surface Deform/蒙皮权重传递、碰撞穿插修正、Blender头部专用Mask、FaceNet/ArcFace 0.85/0.70门禁、遮挡区间逐帧消费、镜头`_vN`自动选版、单集失败比例升级、共享注册表SHA门禁、`style_fallback`阻断及视频I2V/T2V/R2V自动选路/切片/接缝重生。

## 1. 总流程与成片

`项目规格/风格 → 世界观/人物小传 → 故事大纲 → 分集大纲 → 分集剧本 → 剧本审核 → 分镜脚本 → 资产提取 → 人物/服装/道具/场景基准图 → 多角度资产图 → 资产验收 → 需3D资产判定 → Klein‑9B建模参考图 → TripoSR建模 → Blender后台清理/多通道渲染 → 3D结构审核 → 2D身份/风格细化 → 分镜画面 → 画面验收 → 分镜视频 → 视频验收 → 配音 → 口型 → 音效/环境声/BGM → 字幕 → 剪辑/转场/调色/增强/混音 → 合片 → 内容审核/技术质检 → 局部返工 → 母版导出/发布归档`。

适配Seedance、小云雀、MiniMax H3、LTX全系。成片55—65秒、9:16、1080×1920、30FPS、MP4。总时长由对白量、冲突节奏和钩子强度决定并经校验，不得随机取值；各剧情节奏卡点可在不改变0秒起点和55—65秒总时长的前提下前后浮动最多5秒，成片始终不得短于55秒或超过65秒。剧本允许任意长剧情段落；AI视频拆为4—8秒/段，单段≤9秒，禁止≥10秒；多人镜头≤5秒；长镜头分段后无缝拼接。主角人设/服化/气质全剧锁定；单集≤2场景且时辰/天气/光影固定；单集台词唯一无重复。目标：无崩坏、无跳变、无重复、风格统一、合规限流、成本可控。

## 2. 大纲与剧本

- 文本生产模型固定为本地`qwen3-vl:32b`，负责故事总纲、分集大纲、分集剧本和分镜脚本；`qwen2.5:72b`固定负责大纲、剧本、分镜的初审、最多一次自动修正和终审。两者按阶段串行加载并在任务结束后卸载。
- 阶段完整生成后执行72B初审；`needs_fix`最多完整修正一次并终审，终审失败阻断下游。修正不得改变分集数、镜头数、episode、shot_number或既有顺序；长文本按上下文预算连续分批。任务证据必须记录真实模型名。

- 大纲必含强钩子、即时冲突、战力/身份反转、结尾悬念；剧情线为低谷受压→反派升级→隐藏能力/身份触发→反转碾压→下集悬念。
- 分集前先建立全剧状态表：`集数→剧情阶段→唯一核心事件→不可逆变化→反派手段→新信息→伏笔→结尾钩子`；分集只能扩写对应状态。
- 标题和核心事件全剧唯一；能力初现、身份揭晓、试炼结果、反派败退只能首次发生一次，再次出现必须是升级或后果。后续批次必须携带全部既有标题/事件/状态及最近3—5集完整梗概。
- 剧情阶段单向推进：低谷受压→能力/身份触发→被争抢或陷害→绝境升级→秘密揭晓→最终决战；进入后段后禁止退回试炼、初次觉醒或准备决战。
- 每集至少产生一项不可逆变化；禁止原地铺垫、同一冲突换词重演、反派无解释复活。反派连续两集不得复用同类手段。
- 人名必须来自人物白名单且全剧唯一，禁止错字、同音和近形混淆；常驻角色必须明确身份、立场、目标、关系和首次出场集，反派必须具备个人背景、损失风险及差异化动机。
- 节奏：0—5秒钩子、5—15秒铺垫、15—30秒觉醒、30—50秒对峙、50—65秒金句悬念。
- 情绪：压抑→隐忍→坚定→震惊→碾压；台词短句、3—4字/秒，无废话；环境音效只在后期添加，禁止写入AI提示词。
- 剧本“剧情段落”是叙事单元，分镜“镜头”是视觉单元；一个剧情段落可在其起止边界内拆为1—3个镜头。两者时长可独立分配，但对应镜头时长之和必须严格等于原剧情段落时长，整集均须连续覆盖同一个55—65秒总时长。
- 剧本初审或终审失败时，只退回对应分集剧本的问题段修改；不得退回整集大纲、不得全局重写，也不得把未通过内容送入分镜。
- 禁止模糊剧情、无爽点/悬念、多主线、中途改设定、台词堆砌、空镜水时长、爽点后置和平铺直叙。

## 3. 分镜与提示词

- 每镜必填ID、起止时间/时长、景别、机位/运镜、画面、动作、台词、情绪、核心道具、AI锁定、后期备注。
- 景别按全景→中景→近景→特写递进；单集特写≤3；禁止连续两镜画面/动作重复；连续特效≤2段；核心道具全程不得消失或变形。
- 主角动作少慢稳；配角/群演仅微小呼吸晃动，禁止走动、转身、大动作或抢镜。同框≤6人；主角居中、最高权重、最优画质且无遮挡，配角低动态，群演统一姿态；人物层次分明且不得重叠穿插。
- 提示词固定六层：画质画幅→环境时空→人物主体权重→运镜小动作→特效细节→防崩锁定。禁止模糊词、风格堆砌、无分层长句或缺少防畸变词。
- 仅在分镜结构被人工修改、插入或改时长时重排时间轴：从变更点起自动重算全部后续镜头起止时间并保持连续覆盖；普通媒体重试不得挤压或改变已确认分镜时长。中断恢复以最后一个时间轴有效且已持久化镜头的结束时间为接续点，其余镜头按原顺序重新分配。
- 每个包含人物的镜头必须逐人写入`id、costume_id、costume_version、action、change_type`；即使服装延续上一镜也不得省略。`costume_id`变化是显式换装事件，必须由剧本/分镜决定并与剧情动作对齐；AI只执行加载和替换，禁止自行决定换装。
- 全剧换装状态表按`集数、角色、镜头、旧costume_id@version、新costume_id@version、剧情原因`登记。换装镜头前后分别引用旧/新服装；未登记、版本不存在或与角色授权范围不符时阻断分镜画面生成。

## 4. 人物、服化、场景与画风

- 脸型、骨相、五官、气质、头身比、发色发型、主线服装、配饰信物全剧不变且不移位消失；肢体与五指必须完整无畸形。
- 微表情：低谷隐忍淡然、爆发凌厉坚定、对峙清冷压制、收尾深邃留白；禁止歪嘴、瞪眼、空洞、面瘫、狰狞大笑。
- 单集光源固定、面光均匀；禁止阴阳脸、过曝、死黑。特效弱于人物且不遮五官。
- 柔和漫射平光允许自然面部明暗反差，但不得超过真人在同类环境中的自然观察水平；禁止用极致顺滑、高调美颜或无结构匀光换取“通透”。
- 时辰天气固定，场景摆件和建筑细节不得增减或刷新。画风全剧二选一锁定：古风低饱和冷调或都市暖调通透。
- 每集核心参考仅2张定稿：主角定妆图+场景全景图；全剧复用，仅定稿参考预先超分。
- 人物资产卡固定六格：左45°全身基准、0°正面全身、右45°全身、90°侧面全身、180°背面全身、0°正面半身。第一张由Klein‑9B生成并人工确认，且是TripoSR唯一人物几何输入；随后严格逐槽生成、逐槽确认其余五格。左45°同时展示正面与侧面结构，六图共同锁定人物五官、妆发、体型、服装、配饰和视角连续性。
- 道具只生成一张45°三分之二基准图，必须同时展示正面、顶面和侧面结构；场景只生成一张正常人眼高度45°空场景全景，必须展示空间纵深、墙地关系和固定陈设。两者人工确认后自动进入TripoSR→Blender，禁止用2D模型继续补角度；Blender七角度及RGB/Mask/Depth/Normal自动回填资产卡。
- 分镜画面多参考固定映射：0°半身为唯一人脸/妆发/近景表情与口型身份源，0°全身锁体型、服装、鞋履与配饰，左45°/右45°/90°/180°分别锁对应方向轮廓、发长、服装结构与跨角度连续性；六图全部进入生成和一致性审核。
- 场景和重复使用的独立道具默认进入3D；人物和灵兽按混合链进入3D；字幕、特效、面部近景、手部特写、远景群演和一次性微小道具不建3D。完整门禁以`docs/specs/短剧3D资产生产规范.md`为准。
- TripoSR生成的3D渲染图仅用于审核模型结构、姿态、服装/道具的大致对应关系，不执行面部特征相似度比对；面部一致性只由2D身份审核链锁定。
- Blender渲染管线在3D结果进入2D生成器前自动输出头部Mask；2D生成器只能读取遮罩后的身体、服装、姿态、Depth与Normal信息，禁止把3D五官作为最终身份参考。
- 2D身份链必须执行多角度嵌入审核：正面全脸FaceNet/ArcFace余弦相似度≥0.85，侧脸≥0.70；未达标自动驳回并只重绘当前镜头。骨相和五官细节只由2D身份链保障，不依赖3D。
- 3D空间锚必须覆盖原地动作、行走/奔跑、跳跃、受力位移、倒地/跪地、抱起/背负、遮挡/并肩/高低站位、跟拍、环绕、变焦和快速切镜；动态字段、坐标继承及0.1米连续性门禁以`docs/specs/短剧3D资产生产规范.md`第13节为准。
- 3D人物脸禁止直接进入最终成片；多人同框必须按逐人Mask与摄影机深度从远到近分层生成。TTS与动作时长偏差超过0.5秒退回分镜；2D/3D冲突仲裁、系统故障降级、跨项目版本引用、资产ID冲突及多机位视线连续性统一执行`docs/specs/短剧3D资产生产规范.md`。
- 3D到2D固定串行职责：MiniMax H3 Ref2VA先把已确认Blender源视频/渲染结果转换为保留场景结构、空间、遮挡和时序的2D风格结果；Qwen‑Edit随后只在H3成品上执行局部修复、人脸调整和服装细化。两者不得并行、替代或嵌套到同一工作流图。
- 项目LoRA、版本、风格词和默认权重全剧锁定。单镜确有构图或遮挡需要时，只允许人工批准后微调该镜LoRA强度并记录镜头ID、原值、新值、原因和审核结果。单镜连续生成失败3次以上时，可仅对该镜使用一次同底模、同风格、合规索引内的备用LoRA候选，必须人工确认；禁止整集重跑或把例外扩散到其他镜头。
- 服装是`prop`栏中的独立`costume`资产，不属于人物本体。人物本体只锁脸、体型、发型和肤色；日常服、战斗服、礼服、长袍、披风均须独立提取、独立版本、独立3D建模和复用。
- 每套服装当前已实现的链路为：一张Klein‑9B 45°三分之二完整展示图→人工确认→TripoSR独立服装网格→Blender七角度结构审核→按`costume_id`归档。角色基础体加载、服装表面变形/蒙皮传递、碰撞穿插修正和穿衣后H3 Ref2VA→Qwen‑Edit属于`pending_development`；能力完成前不得把独立服装3D冒充已穿到角色身上，也不得自动推进穿衣镜头。
- 服装元数据至少包含`asset_id、asset_type=costume、owner、tags、version、status`；同角色多套服装分别建模，同服装可在授权与体型适配审核后跨角色复用，同版本可跨集复用。重做递增`_vN`并保留旧版。

## 5. 视频、运镜与转场

- 双参考图锁定分片生成；普通镜头I2V、空镜T2V、重点人物/多素材镜头R2V。不得静默替换用户指定模型。
- 分镜画面验收后作为视频首帧约束；模型选择、能力门禁、降级和审计统一执行`docs/specs/视频模型选择规则.md`。
- 视频切点由分镜脚本的起止时间决定，后端负责切片、排队与拼接；相邻段首尾各保留2帧拼接缓冲。拼接失败时，以已通过上一段的尾帧作为下一段首帧重新生成当前接缝，禁止整镜或整集静默重跑。
- 人物穿越门、柱、屏风等遮挡物时，3D空间锚必须登记`occlusion_start_frame、occlusion_end_frame、occluder_id`；2D生成器按该区间逐帧应用人物Mask，禁止从无遮挡直接跳变为完全遮挡。
- 运镜：全景极慢推进、中景微平移、近景小幅推镜、特写微动定格；禁止晃动、旋转、变速、跳帧。
- 转场：铺垫0.2秒淡入淡出、冲突硬切、特写0.1秒微叠化、换场闪白微转场；全部≤0.3秒，禁止花哨转场。
- 杜绝肢体/手部畸形、悬浮穿插、面部错位模糊、场景穿模、瞬移、道具悬浮、频闪、虚影倒影和透视比例错误。

## 6. 配音、字幕与音频

- 角色音色固定，语速3—4字/秒，情绪匹配，无机械断句或人声重叠。
- 字幕使用圆润黑体、白字黑边、单行≤12字、居中偏下并处于平台安全区。
- BGM无歌词且低于人声30%；音效成套统一，无音量波动或堆砌。
- 有对白镜头必须齐备对白音轨、口型和字幕；无对白镜头补等长静音轨。

## 7. 返工、任务与成本

- 小瑕疵后期修复；中度单镜重绘≤2次；重度单镜重造。禁止单镜问题整集重跑。
- 只失效问题节点及下游，禁止清空无关已确认成果；分镜片段不单独超分，拼接后仅最终成片超分一次。
- 重绘/重造版本必须递增`_vN`且保留旧版；下游合片默认引用最新审核通过版本，旧版仅供回溯。版本切换由3D空间锚中的`shot_id`关联并写入依赖快照，禁止覆盖同ID旧版或引用未通过候选。
- 单集失败镜头超过总镜头数30%，或连续5镜因视觉崩坏、身份漂移、时长偏差反复失败时，暂停该集、锁定现有有效成果并转人工介入；禁止自动启动整集重跑。
- 重任务必须具备唯一任务ID、实际进程、prompt ID、阶段、心跳、超时、定向停止、重启回收和终态保护。通用重任务普通失败最多重试1次；3D资产链按当前执行器分阶段计数，Klein最多2次、TripoSR最多3次、Blender最多3次，并服从`短剧3D资产生产规范.md`的不可重试错误、内存门禁和24小时独立job累计规则。
- 停止/失败/超时必须终止自身进程树、释放模型和通道；看门狗回收有状态无进程及有进程无状态。
- 3D建模独占GPU；运行期间生图和生视频进入同一可见重任务队列。生图与生视频也必须串行执行，任务中心显示排队序号、阶段、心跳和预计资源，禁止绕过队列并发抢占。

## 8. 合规、连载、质检与归档

- 交付SOP：编剧完成大纲/剧本→分镜师标准化分镜→画师锁定参考图→生成/剪辑→分级返工→合片质检→导出归档。
- 不过度磨皮；台词无极限词、敏感或违规负面内容；无高频频闪。流量节奏执行3秒钩子、15秒小爽点、30秒大冲突、结尾强留存。
- 全剧画风、光影、运镜、特效统一；核心造型不变仅气场进阶；关键道具/特效有序迭代；固定场景构图复用。
- 必检：人设统一、无崩坏、镜头不重复、时长/画质/编码合规、台词合规且不重复、特效连贯、音频正常、结尾有悬念。
- 大纲必检：标题/核心事件唯一、人名白名单、阶段单向、角色与反派状态连续、伏笔有登记和回收；任一失败只重写问题集，禁止问题内容进入剧本。
- 归档：`剧集名_集数_镜头ID_素材类型_版本`；保留母版、发布版、字幕、音轨、审核记录、模型/工作流版本、任务ID和来源。
- 资产ID由系统在首次资产提取时生成，格式`{project_id}_{asset_type}_{asset_name}_{version}`，并在当前租户资产域内保持2D/3D全局唯一；人工修改必须审批。公共3D资产由`data/shared/3d/registry.json`锁定精确版本与SHA-256，校验不一致时禁止引用。
- 项目创建时依据用户已选“题材+年代+画风”匹配预置风格映射；无精确匹配时标记`style_fallback=true`并阻止生图，等待人工确认，禁止静默切换默认LoRA。题材参数执行`docs/specs/题材音画参数模板.md`。

## 9. 人工关口与黑名单

人工确认：剧本→分镜、分镜→资产、基准图→多角度图、资产→分镜画面、画面→视频、音视频字幕→合片、审核→导出。禁止自动越级或空产物伪装完成。

剧本审核失败必须遵循第2节的问题段闭环；只有对应问题段复审通过，才允许进入分镜。

黑名单：单段≥10秒；镜头/动作/台词重复；配角抢镜；提示词模糊堆砌；特效遮脸；时空光影跳变；花哨超时转场；表情僵硬狰狞；透视比例错误；爽点后置；无悬念收尾；整集重跑；单镜单独超分；未确认自动推进；未真实完成却写成功。
