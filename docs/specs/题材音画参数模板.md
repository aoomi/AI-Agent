# AI短剧题材音画参数模板

版本：1.0｜生效日期：2026-08-10｜目标验收规范

当前实现状态：`pending_development`。题材映射、共享SHA门禁和`style_fallback`运行时阻断尚未全部接入；正式动态测试通过前，本表只定义验收目标，不得宣称系统已自动执行。

LoRA字段是项目风格映射键，不是任意文件名；必须由正式索引解析并校验底模、SHA-256与许可。索引无精确匹配时标记`style_fallback=true`并暂停，禁止静默使用默认LoRA。
