# AI短剧视频模型选择规则

版本：1.2｜生效日期：2026-08-11｜执行与验收规范

当前实现状态：`partial_production`。正式`/api/videos/generate`已接入两条显式路线：同时具备已确认Blender源视频和已确认人物正面定妆照时使用本地MiniMax H3 Ref2VA；其余已验收分镜画面保留Wan2.2 I2V。T2V、通用多素材R2V自动选路、跨段2帧缓冲和接缝局部重生仍为待开发项，禁止伪装执行。

MiniMax H3 Context IR提示词优化节点已正式接入Ref2VA路线，执行边界见`docs/specs/H3 Context IR提示词优化节点.md`。它在独立Comfy工作流中先生成并落盘结构化提示词，卸载32B模型且释放Comfy后，原Ref2VA工作流才可启动；两图禁止嵌套或并行。

## 1. 输入与选择

- 分镜画面必须先验收；通过后的画面作为视频首帧和构图约束，禁止使用未审核图。
- 普通单参考镜头使用I2V；纯空镜且不要求主体身份连续时使用T2V；重点人物、多人或多素材融合镜头使用R2V。
- H3 Ref2VA固定把`<Video 1>`解释为Blender几何、运镜、遮挡和时序参考，把`<Picture 1>`解释为唯一2D人物身份参考；两条工作流通过磁盘成品交接，禁止嵌套模型。
- H3源视频不接收音频参考，也不解码或封装模型自生音轨；官方Ref2VA节点内部必填的audio VAE仅保留用于AV latent结构。权威对白、音效和混音只由后续独立音频与口型阶段产生。
- H3输入必须同时来自已确认的3D资产版本和人物正面定妆照；缺任一项不得假装使用H3，回到既有Wan2.2 I2V路线。
- Seedance、小云雀、MiniMax H3、LTX只在本地/服务能力、许可、分辨率、时长和输入类型门禁全部通过时进入候选；用户指定模型不得静默替换。不可用时任务进入`model_blocked`等待人工选择。

## 2. 分段与拼接

- 后端按分镜起止时间切为4—8秒段，单段≤9秒；多人复杂段≤5秒。
- 相邻段首尾各保留2帧缓冲，按镜头ID、段序号和原始时间码拼接。
- 接缝验收检查身份、姿态、光影、空间锚、运动方向和音画时间码。失败时固定上一段已通过尾帧为下一段首帧，只重生成当前接缝段；禁止整镜或整集重跑。

## 3. 任务与审计

- 视频与生图串行；3D任务运行时两者排队。每段记录模型、版本、工作流、prompt/task ID、输入哈希、首尾帧、时间码和审核版本。
- 失败、停止、超时必须定向取消自身模型任务、释放显存并保留已通过分段；下游只读取最新审核通过版本。
- owned Comfy prompt只有在queue确认消失后才算取消完成；未确认时任务保持`cancel_pending`且资源票据不释放。看门狗必须修复`completed/failed/cancelled`但prompt仍running/pending的矛盾状态，再恢复原终态。
- H3记录独立Comfy prompt ID、`h3_rv2v`阶段、源视频和身份参考URL；成功、失败、停止、超时、服务恢复和关闭均精确取消自身prompt并释放模型。
- Context IR记录独立`h3_context_ir`阶段、prompt ID、心跳、尝试次数及`optimized_prompt/selected_skills/raw_json`磁盘路径。H3必须使用已落盘的非空`optimized_prompt`；Context失败、历史异常超过容错、超时、取消、持久化失败或模型仍驻留时任务失败，禁止退回原提示词冒充优化。
