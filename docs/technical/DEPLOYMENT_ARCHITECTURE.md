# 部署架构

版本：1.0  
状态：设计基线

## 部署单元

- 前端：独立静态资源服务。
- 平台 API：身份、契约、插件、任务和数据访问入口。
- 工作器：执行模型、媒体和长任务，与 API 进程隔离。
- 存储：结构化数据库、对象/文件存储、任务状态和审计日志分层。
- 外部能力：LangGraph、Dify、ComfyUI 和模型服务通过适配器连接。

## 部署形态

- V1.0 本地：单机进程可组合部署，但数据和进程职责仍分层。
- 私有化：客户网络内独立部署、独立密钥和独立数据。
- SaaS：租户上下文贯穿 API、队列、存储、日志和插件实例。

具体安装与操作步骤只在 `../operations/` 维护；本文件不复制命令和故障处理流程。
