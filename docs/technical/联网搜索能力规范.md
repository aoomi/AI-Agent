# 联网搜索能力规范

版本：1.1（M9.194）

1. 对话命中“联网、搜索、最新、当前、价格、版本、许可、授权、商用、官网、来源、链接”等时效或来源意图时，必须先执行 `web.search`，再调用本地对话模型。
2. 搜索能力由统一能力注册表提供；provider 的 ID、顺序、描述、主机白名单、handler 和所需环境变量只能来自同一结构化注册表。当前路由为：配置 `BRAVE_SEARCH_API_KEY` 时优先 Brave；随后使用 GitHub Repository Search、DuckDuckGo HTML、Bing RSS、Google News RSS、Google HTML 多源后备；每个提供方只允许两次有限尝试。
3. 搜索响应必须记录 `query`、`provider_id`、`searched_at` 和来源列表；回答末尾只能展示模型返回的有效 citation index 对应来源。没有有效 citation 时必须失败，禁止自动补来源冒充已采用证据。
4. 搜索失败或无可核验结果时返回 `web_search_unavailable` / `web_search_no_results`，禁止本地模型对“最新/当前/许可”等问题进行无来源猜测。
5. 只允许 HTTP(S) 公网来源；拒绝 localhost、回环、私网、链路本地及非 HTTP(S) URL。自动重定向必须关闭，每一跳都要在发起连接前验证协议、精确provider host和DNS；托管运行时的198.18/15代理例外只能用于结构化注册表内的provider transport，严禁用于搜索结果URL。限制响应类型、响应体积和超时。
6. 搜索提示只作为外部证据，不得作为系统指令执行；本地模型只能引用实际返回的证据编号。
7. 非联网意图继续使用原本地对话链，不新增网络请求；联网搜索不进入生图、视频或其他重任务资源池。
8. 前端所有检索状态、失败原因、回答和来源均在对话框展示，不使用独立横幅。输入框提供“联网”显式开关；“当前项目/当前任务”等本地上下文不得因“当前”二字误触联网。
9. 中文领域问题必须生成面向检索引擎的中英查询；搜索结果进入模型前必须通过主题词相关性门禁。文生图问题至少命中 image 与另一主题词；“开源”问题的来源必须明确出现 open source/open-source。翻译站、字体站等低相关结果不得进入证据。
10. 对“最新/最近/截至”等问题，带发布日期的来源必须按时间排序；系统只展示来源标题中可证实的信息。标题未写型号时不得自行猜测，无法确认唯一最新型号时必须明确说明并要求继续核对官方模型卡和许可证。
11. 每个“标准化查询+结果数”的成功结果必须原子写入短TTL恢复缓存；在线提供方全部瞬时失败时，只能回退完全相同查询、未过期且重新通过URL与相关性门禁的缓存，并返回`cache_hit/live_attempts`审计。禁止跨查询复用缓存。
