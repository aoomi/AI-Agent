# 前端工程配置说明

版本：2.0  
日期：2026-08-07

## 技术基线

- Vue 3、TypeScript 严格模式、Vite、vue-tsc。
- 版本以 `frontend/package.json` 与 `frontend/pnpm-lock.yaml` 为准。

## 标准命令

- `pnpm dev`：本地开发。
- `pnpm typecheck`：类型检查。
- `pnpm build`：正式构建。
- `pnpm preview`：预览正式构建。

## 当前装配

- `frontend/src/main.ts` 启动平台并加载短剧插件样式。
- `frontend/src/App.vue` 装配平台任务中心、系统 AI 面板和插件插槽。
- `plugins/builtin/short_drama/frontend/register.ts` 注册短剧工作台。
- `plugins/builtin/system_agents/frontend/register.ts` 注册系统 AI 配置界面。

## 强制边界

- 页面不得裸请求、硬编码接口或伪造业务状态。
- 平台服务进入 `frontend/src/services/`，平台状态进入 `frontend/src/stores/`。
- 行业组件、服务、Store 和样式只进入对应插件前端。
- 业务字段在统一 API Client 边界完成 `snake_case` 与 `camelCase` 转换。
