影序AI｜短剧AI生图极简正式规范（可直接落地）
适用范围：AI短剧分镜生图、人物/道具/场景资产统一 | 设备：Mac 128G | 合规模型：InstantCharacter、OpenPose、ControlNet（全商用开源）
一、资产基准规则（核心红线）
判定标准：出场≥2次 = 公共资产，必须先做全套基准图，再生分镜；仅出场1次无需基准图
1. 人物基准图（4张必出）
正面近照、正面全身、严格90°侧面全身、严格180°背面全身
✅ 规范：纯色空背景、中性无表情、标准体态、无夸张动作 | ✅ 每套戏服单独一套基准图
正面近景基准光照：正前方柔和漫射平光，面部左右亮度基本一致，仅下颌与颈侧保留浅淡过渡阴影；肤质纹理清晰通透，服装保留自然层次且不得死黑；背景固定为纯色哑光中性灰，禁止光斑、渐变、硬阴影、侧逆光和强明暗对比。
正面近景面部优化：弱化额头高光与下颌阴影，统一瑕疵，补充柔和眼神光，校正眉眼对称，保持面部亮度均衡。
正面近景强制尺寸与构图：输出固定为928×1664竖图；面部从发际附近至下颌的高度必须占画面40%—50%，自动裁切目标固定为45%；完整头发、发顶、左右耳、下颌、颈部、双肩与上胸必须全部位于画框内，禁止头发、耳朵、下巴和肩部贴边或被截断；发顶上方必须保留约5%画高、左右两侧各保留约2%画宽的纯背景安全边距；人物水平居中，双眼平视，InsightFace偏航角与翻滚角绝对值均不得超过7°；背景为纯色哑光中性灰。该构图为人物正面近照唯一允许样式，生成结果必须先执行单脸检测、发顶与发宽检测、928×1664规范化裁切和0°正脸硬验收，再进入人工“就要这张”确认。
人物四图强制流程：`FLUX.1 Schnell GGUF Q8_0 + 对应项目风格 LoRA`生成正面近照 → 人工“就要这张”确认 → 远程CUDA `Visual Persona + 预置7.5头身OpenPose`生成928×1664正面全身（零LoRA、零Qwen）→ 人工“就要这张”确认 → 远程CUDA `PSHuman`读取确认全身图，重建同一人体网格并渲染严格90°侧面与严格180°背面。未确认正面全身图时，PSHuman必须阻断；禁止从近照推断并宣称锁定不可见的下半身服装。Visual Persona与PSHuman必须分别通过代码、权重、数据与依赖许可证门禁且配置真实服务地址；未配置时明确失败，禁止回退到独立FLUX扩图或SDXL多次抽卡。固定角度阶段禁止加载项目风格或人物LoRA，禁止加载Qwen；Qwen-Edit仅允许用户主动执行局部修复。
人物全身图强制尺寸与构图：固定928×1664；完整发顶必须入框但不强制顶部留白，完整鞋底最低点下方必须保留约5%画高纯背景；完整头顶、双手、双腿、脚踝、双鞋和鞋底必须入画。三视图统一使用预置7.5头身标准OpenPose PNG，禁止运行时动态手绘骨架；头身比必须为7.0—7.8，大腿与小腿长度差≤8%，上臂与小臂长度差≤10%，躯干高度不得低于下肢高度的55%。侧面脸角必须为88°—92°且躯干偏转≤3°；任一角度、比例、边距、人脸相似度或服装相似度不通过即自动淘汰。
2. 道具基准图（4张必出）
平视正视、右45°斜侧、左45°斜侧、低角度仰视
✅ 规范：单独摆放、无人物入镜、结构完整无畸变
道具硬验收：画面只能包含一个独立可拿取道具本体，采用无缝纯中性灰产品摄影背景；禁止建筑、房间、商店、街道、门窗、家具、柜台、山水、花木、招牌、海报、文字、人物、人体及其他陪衬物。道具不得加载人物风格 LoRA；`exactly_one_isolated_prop`、`plain_neutral_background`、`no_scene_or_environment`、`no_text_or_signage`、`no_live_person_or_body_part`必须全部为true。
3. 场景基准图（4张必出）
平视全景、45°斜侧全景、低角度仰拍、微俯视全景
✅ 规范：空场景无任何人、家具墙体位置固定、仅可修改光影，不动结构
场景与分镜文字强制采用两段式确定性流程：仅提取“写有、写着、题字、字样、显示、招牌、牌匾、门匾、石碑、卷轴”之后明确指定的文字；扩散生图阶段删除目标文字并要求对应区域留白、禁止生成任何字形；成图后使用本机字体程序精确绘制原始Unicode文字。若模型未生成可承载文字的牌面，程序必须补充深色中性牌面后再写字。最终图片必须记录目标文字、字体、排版方向、锚点、文件SHA256与`exact_source_render`审计结果。人物基准图与普通道具图禁止触发该流程；不得将扩散模型生成的伪字、乱码作为最终文字。
二、表情绝对规则（彻底杜绝情绪错位）
1. 基准图：零情绪、中性平淡脸，只锁定五官脸型，不固化表情
2.分镜图（唯一需要表情）：按剧本情绪写入对应眉眼、面部肌肉状态，匹配后期语音情绪
三、通用固定提示词（全局默认携带）
正向核心词
国风厚涂，电影写实质感，8K高细节，柔和电影布光；人体骨骼解剖正确，无反关节畸形；五官自然，面部微纹理细腻；场景道具结构透视准确；镜子仅反射成像，无实体人物；严格匹配基准图人物、道具、场景特征，无漂移变形；动作带预备与收尾缓冲，过渡顺滑
反向屏蔽词
五官崩坏、木偶脸、肢体畸形、多指缺指；镜内实体人物；人物脸型服饰漂移、道具变形、场景结构错乱；镜头滑动漂移、自动运镜；文字水印、噪点结块、塑料脸；主体裁切截断
四、专项镜头提示追加规则
1. 常规镜头（默认）
正向：固定机位，镜头全程静止，禁止平移推拉，背景位置不变，仅人物动作
反向：镜头漂移、画面滑动、机位偏移
2. 镜面镜头
正向：镜面仅反光成像，镜中人左右镜像对称，镜框位置固定
反向：镜内生成独立实体人物、镜面空间化
3. 主动运镜镜头
禁止模糊描述，必须精准标注：角度、方向、匀速、速度平缓
五、常用情绪表情模板（分镜专用）
平静：表情柔和，眼神松弛，轻微眨眼
愤怒：眉头紧锁，咬肌收紧，眼神锐利，肩部绷紧
委屈：眉眼微蹙，眼眶泛红，嘴角下压，面部轻紧绷
窃喜：眉眼舒展，嘴角微扬，表情含蓄自然
六、工程硬性参数（防崩、防错、商用合规）
1. 内存限制：Mac128G 峰值≤90GB，预留35GB+系统内存，禁止多任务并发
2. 模型合规：身份模型必须逐项记录来源、许可证、版本与权重哈希；未完成许可证门禁的InstantCharacter、InstantID、PuLID或IP‑Adapter‑FaceID仅限测试，禁止登记为商用生产模型。
3. 姿态控制：固定标准OpenPose权重0.80；侧面Depth ControlNet权重0.65；采样30步。固定角度阶段零LoRA、零Qwen。
4. 分辨率：单图长边≤1920，禁止超大图批量生成
4.1 人物正面近照固定分辨率928×1664，禁止使用其他尺寸；自动裁切必须采用45%脸高、5%发顶安全边距和左右各2%安全边距。
5. 视频规则：图生视频只出无声片段，音频、对口型、字幕全部后置
6. 片段时长：单段≤8秒，长镜头拆分串行生成，防时序漂移
7. 画内文字：扩散模型只生成无字底图，准确文字由确定性字体渲染层后置合成；源字符串与渲染结果哈希必须写入元数据，禁止依赖扩散模型拼写。
七、标准化流水线（固定顺序，禁止颠倒）
1. 剧本标注：每条分镜绑定【台词+情绪标签】
2. 前置资产：按人物四图强制流程串行生成并通过两个人工确认关口，锁定一致性
3. 分镜生图：载入基准+骨骼约束+剧情表情，输出静态分镜图
4. 图生视频：生成无声短视频片段
5. 片段拼接：合成完整成片
6. 音频制作：TTS匹配剧本情绪生成台词音频
7. 后期优化：LivePortrait微调微表情 → Wav2Lip‑G局部对口型（仅嘴部）
8. 成品输出：生成SRT字幕、FFmpeg烧录、叠加音效BGM
故障原则：表情、口型出错，优先后期修复，禁止重跑生图、生视频
八、两级稽查标准
初审（自动拦截）
人物/道具/场景与基准不一致、镜面逻辑错误、肢体五官畸形、镜头漂移、画面情绪与台词严重不符
终审（人工核验）
表情情绪匹配、动作逻辑自然、资产无穿帮、口型同步、运镜合规
九、绝对禁止行为
1. 基准图添加戏剧表情、复杂场景
2. 图生视频阶段带入音频
3. 使用非商用锁脸模型
4. 对口型修改全脸，仅允许局部嘴部渲染
5. 依赖对口型模型生成面部情绪
6. 大分辨率批量并发生图，导致内存溢出
7. 场景基准图带入人物
