# 测试策略

版本：1.0

## 测试层级

- 单元测试：纯函数、校验、状态转换、幂等键和迁移。
- 契约测试：OpenAPI、共享类型、插件 manifest 和事件 schema。
- 集成测试：适配器、队列、存储、安全和插件生命周期。
- 端到端测试：从用户页面入口操作到真实任务、产物和刷新恢复。
- 安全测试：越权、路径穿越、上传伪造、密钥泄露、跨租户访问和插件沙箱。

## 强制场景

每个长任务验证成功、失败、超时、取消、重试、刷新、服务重启和不合作执行器；每个人工关口验证不能被恢复逻辑绕过。

## 交付门槛

- 类型检查、构建和 lint 无新增错误。
- 变更相关自动测试通过。
- 真实用户路径和一个直接异常路径通过。
- 产物可加载、可播放或可解析，刷新后仍可恢复。
- 未覆盖项记录到风险台账，不得隐瞒。
