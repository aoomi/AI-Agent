# 架构决策记录（ADR）

ADR 用于记录会长期影响目录、契约、数据、部署和插件生态的技术决定。

## 索引

- `ADR-0001-four-layer-architecture.md`：四层架构与依赖方向。
- `ADR-0002-single-source-docs.md`：目录、命名、产品和契约唯一事实源。
- `ADR-0003-orchestration-adapters.md`：LangGraph 编排与 Dify/ComfyUI 适配边界。
- `ADR-0005-3d-model-storage.md`：三维重建模型权重目录边界。

每个 ADR 包含状态、背景、决定、替代方案、影响和回退条件。已接受 ADR 不直接删除，变更时由新 ADR 标记替代。
