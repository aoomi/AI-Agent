# ADR-0005：三维重建模型权重目录

状态：已接受  
日期：2026-08-10

## 决策

新增 `models/3d/`，作为三维重建、单图转网格和几何生成模型权重的唯一正式目录。模型源码继续归属业务插件或外部隔离运行环境，运行缓存与生成网格不得写入该目录。

首个登记模型为 `models/3d/TripoSR/`，来源固定为官方 Hugging Face 仓库 `stabilityai/TripoSR`，许可证为 MIT。

## 约束

- 权重、配置、模型卡与许可证证明必须同目录保存。
- 运行产物进入 `output/`，缓存进入 `data/`。
- 未经完整性校验的文件不得登记为可用模型。
