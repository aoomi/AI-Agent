# AI Agent 项目愿景

版本：2.0  
生效日期：2026-08-07  
职责：项目长期目标、建设方向和阶段路线的唯一来源。

## 一、项目定位

AI Agent 是可插拔、可配置、可对话操作的 AI 应用平台。用户能够添加 Skill、为 Skill 自动生成独立智能体、选择模型，并通过对话完成复杂配置与任务。平台面向本地、私有化和 SaaS 部署，共用同一套契约、任务、事件、权限、模型和插件底座。

## 二、核心产品能力

1. Skill 与智能体：每个 Skill 对应独立智能体、身份、上下文、状态和权限。
2. 模型配置：每个智能体独立选择已注册模型，按能力、成本、上下文和部署范围约束。
3. 对话控制：通过对话创建配置提案、确认变更、执行复杂任务、查看状态并恢复失败流程。
4. 双 AI 协作：主线开发 AI 可写，稽查 AI 永久只读；两者可选择不同模型并串联协作。
5. 插件平台：行业流程、模型工具和前端扩展均通过标准插件接入。
6. 任务与资产：长任务可停止、恢复、追踪；产物版本化、可追溯、可局部失效和导出。
7. 安全隔离：项目、身份、租户、会话、插件和智能体上下文默认隔离。
8. 全行业流程机器人：一个业务流程对应一个独立 Skill 机器人，每个机器人可独立选择模型，并通过 LangGraph 组成行业工作流。

## 三、首个业务闭环

短剧插件覆盖项目需求、大纲、剧本、分镜、资产、图片、视频、音频、字幕、合片、审核与导出。所有生成能力使用真实提供方，人工确认关口不可绕过。

## 四、长期建设路线

### 阶段 A：平台与契约

- 完成身份、租户、项目、任务、插件、模型、资产、错误和事件契约。
- 完成可安装运行入口、事件、队列、插件生命周期与模型注册。

### 阶段 B：智能体与对话配置

- 将开发 AI、稽查 AI 和行业能力全部 Skill 化。
- 支持模型选择、配置版本、权限策略、对话提案、确认与复杂任务执行。
- 支持多智能体串联、并行、停止、恢复和人工接管。

### 阶段 C：业务插件量产

- 完成短剧真实生产闭环。
- 沉淀可复用的文字、图片、视频、音频、审核和导出能力。
- 支持客户自定义插件和私有模型。
- 沉淀行业无关的流程 Skill 模板，使短剧及其他行业使用同一套机器人注册、模型配置、对话和编排机制。

### 阶段 D：交付与商业化

- 完成安装、升级、回滚、备份恢复、灾难恢复和可观测性验收。
- 按版本规划启用私有化授权、多租户、配额、计费、集群和合规能力。

## 五、永久原则

- `.kernel/` 只读，行业业务不进入 `platform/`。
- 前端只展示真实任务与真实产物。
- 稽查权限不可通过配置扩大。
- 模型和外部工具可替换，业务契约保持稳定。
- 配置、任务、资产和 Prompt 全部版本化并可追溯。
- 同一事实只由一个文档维护。
