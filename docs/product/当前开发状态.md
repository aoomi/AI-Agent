## 使用口径

1. “当前状态”只从上表读取；其他四份记录负责计划、缺陷详情、进度证据和长期记忆，不再分别裁决当前状态。
2. 表内删除条目表示该工作已完成完整闭环；删除前必须把最终状态及证据同步到对应历史记录。
3. 被后续里程碑覆盖的旧方案必须明确写“历史”或“已被 Mx 覆盖”；不得再次加入本表。
4. 状态变更必须运行 `python3 scripts/maintenance/check_document_status.py`。检查会拒绝重复 ID、未知状态、缺失 BUG 详情、索引与 BUG 首状态冲突及第二当前状态事实源。
