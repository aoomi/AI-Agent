# AI Agent V1.0 产品需求

版本：1.0  
状态：基线需求  
生效日期：2026-08-07

## 一、V1.0 目标

交付可在本机运行的通用平台基础能力，并以短剧插件验证插件发现、能力调用、任务执行、资产展示和人工确认的完整闭环。

## 二、平台基础需求

1. 用户能够进入工作台，管理项目、任务、Skill、工具和个人设置。
2. 项目、用户、会话和任务具有稳定身份键，切换项目不得串数据。
3. AI 对话支持文本及图片/视频输入；历史、长期偏好和项目内容按范围隔离。
4. 长任务支持排队、停止、失败、恢复和真实进度，刷新不得重复创建任务。
5. 插件能够声明能力、依赖、权限、兼容版本和前端插槽；平台拒绝不兼容或越权插件。
6. 页面不得直接绑定外部工具私有接口，所有跨层数据通过共享契约。

## 三、短剧插件需求

短剧插件按大纲、剧本、分镜脚本、资产、分镜画面、分镜视频、成片、导出组织用户流程。具体生产参数、审核和批次规则在后续短剧插件 PRD/流程规范中维护，不写入平台 PRD。

## 四、用户可见验收

- 无项目时展示真实空状态，不出现演示项目、演示素材或伪任务。
- 创建、切换、刷新和重新进入项目后，页面显示与服务端真实状态一致。
- 未启用能力显示可理解的缺失说明或导入替代入口，不伪装完成。
- 人工确认前自动流程停止；确认后仅放行已确认范围。
- 失败时显示原因、已保留进度和可重试范围。

## 五、V1.0 非交付项

SaaS 计费、公共插件市场、跨租户运营后台和集群高可用只按 `产品迭代规划.md` 进入后续版本，不得在 V1.0 伪实现。
