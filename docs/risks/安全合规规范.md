# 安全合规与数据隔离风控规范
文档版本：1.1
生效日期：2026-08-07
文档路径：docs/risks/安全合规与数据隔离风控规范.md
适用角色：后端 / 前端 / AI 全自动开发、架构、运维、交付负责人
生效场景：AI 短剧全自动生产系统 V1.0（个人本地）/V2.0（私有化部署）/V3.0（云端 SaaS）全版本迭代
核心定位：统一代码安全、数据安全、权限隔离、内容合规、商业化风控全套强制标准，约束 AI 自动编码行为，杜绝泄露、破解、违规、资金风险；遵循「底层统一、逐级增强、增量迭代、不降级、不重构」原则
核心原则
1. 五位一体安全框架：代码工程安全 + 数据存储隔离 + 权限访问管控 + AI 内容合规 + 商业化资金风控
2. 版本分层能力：V1 基础本地安全 → V2 私有化交付安全 → V3 云端强监管合规
3. AI 开发强约束：所有自动生成代码必须通过安全校验，不合规禁止提交 Git
4. 兼容底线：新版本必须完全兼容旧版安全逻辑，不得删减历史安全能力
一、整体安全总则
1. 所有密钥、授权、隐私、付费数据全程禁止明文存储 / 明文传输，统一加密 + 脱敏双机制；
2. 任何接口、功能入口必须加参数校验、权限校验，禁止裸暴露、无鉴权；
3. V1/V2/V3 底层安全内核统一复用，仅上层风控能力增量新增，底层加密 / 隔离逻辑禁止修改；
4. 私有化版本增加防破解、防篡改、离线安全兜底；SaaS 增加多租户物理隔离、监管审计能力；
5. 全系统操作、AI 生成内容、资金变更、权限修改全部留痕可审计。
二、代码与工程安全规范
2.1 敏感资源管控强制规则
1. 密钥（模型密钥、数据库密钥、支付密钥、授权 License 密钥）、API 凭证、客户隐私信息统一存入加密配置库，禁止写死代码、禁止提交 Git；
2. 本地日志、私有化输出日志自动脱敏：自动过滤密钥、Prompt 核心商业逻辑、手机号、付费账号；
3. 配置文件区分开发 / 测试 / 私有化客户 / SaaS 环境，禁止线上配置泄露至本地代码仓库。
2.2 AI 自动编码安全红线（强制执行）
AI 生成所有接口、后台逻辑、脚本必须满足以下校验，不达标自动拦截上传：
1. 禁止无鉴权接口、无参数校验接口、直接拼接 SQL/HTTP 参数（防注入）；
2. 禁止越权逻辑：普通账号直接读取管理员、其他项目 / 租户数据；
3. 禁止硬编码密钥、明文打印隐私数据；
4. 禁止跳过风控、内容校验逻辑；
5. 新增功能必须同步配套权限、隔离、风控代码，只做业务不做安全直接驳回。
2.3 V2.0 私有化专属工程防护
1. 程序二进制 / 脚本防篡改、防二次打包、虚拟机环境拦截；
2. License 机器码绑定、时间加密校验，授权文件加密存储；
3. 离线部署断网不失效，仅限制新增高级功能，存量生产不受影响；
4. 客户交付包剥离内部开发密钥、测试凭证，只保留客户独立授权。
2.4 版本代码隔离要求
V1/V2/V3 分支安全底层代码完全复用，各版本业务安全逻辑增量叠加；禁止将 SaaS 付费、多租户逻辑写入 V1/V2 分支。
三、分版本数据隔离规范
3.1 V1.0 个人本地数据隔离（单人自用）
适用场景：仅本机单人使用，无团队、无对外交付
1. 多项目数据、素材缓存、任务队列、配置完全隔离，跨项目无法互相读取；
2. 本地任务算力、产出文件独立目录，自动区分存储路径；
3. 本地密钥采用设备加密存储，仅本机可解密；
4. 无多租户、无团队权限，仅单用户全局权限。
3.2 V2.0 私有化部署数据隔离（企业客户内网）
适用场景：客户本地服务器、小团队多人使用
1. 项目资产加密存储：客户剧本、分镜、商业方案文件夹加密，防止拷贝窃取；
2. 账号权限隔离：管理员 / 操作员分级，子账号仅可见自有任务，无法删除核心项目；
3. 日志自动脱敏输出给客户，屏蔽我方底层算法、核心 Prompt；
4. 单机 / 局域网数据不对外公网传输，无云端同步；
5. License、设备绑定信息加密入库，禁止明文落地。
3.3 V3.0 云端 SaaS 数据隔离（多企业商用平台）
适用场景：公网多租户、企业团队多人、付费商业化
1. 租户全局隔离：所有业务表强制携带tenant_id，查询必带租户过滤；不同企业数据逻辑 + 物理双层隔离；
2. 企业团队精细化权限：主账号可分配子账号，支持「仅查看本人项目 / 查看全团队项目」两种模式；
3. 用户隐私全脱敏：手机号、微信、支付账号存储时脱敏展示，导出报表自动掩码；
4. 付费账单、充值记录独立隔离，仅企业管理员可见；
5. 云端数据异地定时灾备，租户误删支持数据回滚。
3.4 通用数据禁止行为
1. 禁止跨项目、跨客户、跨租户直接读取数据；
2. 禁止批量导出全量隐私 / 付费数据；
3. 禁止物理删除业务数据，统一使用deleted_at软删除；
4. 批量 AI 生成素材自动归属对应项目 / 租户，不全局混存。
四、AI 内容合规风控规范
4.1 全版本通用基础风控（V1/V2/V3 均启用）
1. 内置全局敏感词库：涉政、色情、暴力、侵权关键词自动拦截 Prompt 与生成画面；
2. 高危模型黑名单：限制违规、未商用授权模型调用；
3. 高危生产操作拦截：批量违规渲染、无限制批量生成自动阻断；
4. 产出素材内嵌隐形溯源水印，区分生成账号 / 项目。
4.2 V1.0 本地轻量合规
仅本地内存拦截违规内容，无全量审计日志，不联网上传内容记录。
4.3 V2.0 私有化客户合规
1. 支持客户自定义敏感词库，适配行业内容管控要求；
2. 违规任务本地标记，可导出合规报表用于客户自查；
3. 不向公网上传内容审计数据，所有审计日志本地留存。
4.4 V3.0 SaaS 全网强监管合规
1. AI 剧本、画面、台词全量实时审计；
2. 违规任务自动封禁，留存完整操作人、Prompt、产出溯源记录；
3. 违规账号分级处理：警告→限制算力→永久冻结；
4. 审计日志云端长期归档，满足网信、内容监管备查要求。
五、V3.0 专属商业化平台风控（仅 SaaS 版本落地，V1/V2 仅预留架构）
5.1 用户行为风控
1. 恶意注册拦截：IP、设备、手机号多维度识别批量刷号；
2. 薅羊毛管控：新用户试用额度限制、多设备同账号限流；
3 异常高频任务自动限流，防止单用户占用平台全局算力。
5.2 算力资源风控
1. 每个租户配置算力 / Token 月度上限，到达阈值预警；
2. 超额自动降并发、暂停新建任务，充值恢复；
3 全局算力均衡调度，单租户超高并发自动限流保护其他用户。
5.3 租户状态风控
1. 额度欠费：只读权限，禁止新建任务，保留历史项目查看；
2. 内容违规 / 资金异常：冻结算力，提供申诉解冻审批流程；
3. 到期套餐自动降级，不直接清空用户资产。
5.4 支付与资金风控
1. 充值、退款、账单全链路日志留存；
2. 重复下单、虚假支付、大额退款自动风控拦截；
3. 企业发票信息加密存储，财务数据独立隔离；
4. 分账、分销返佣数据单独审计，防止渠道套利。
5.5 代理渠道风控
1. 代理额度分级管控，下级租户消费实时统计；
2. 返佣结算留痕，异常下级批量注册自动预警；
3. 代理后台权限隔离，仅可查看自有渠道客户。
六、AI 自动化开发强制安全红线（不可突破）
1. AI 不得私自新增无鉴权、无风控的接口 / 后台功能；所有业务功能必须配套权限、隔离、校验逻辑；
2. AI 禁止修改底层加密、数据隔离、审计核心代码，仅允许增量扩展上层业务风控；
3 新版本安全逻辑必须向下兼容，不得删减旧版本任何安全校验能力；
3. AI 生成代码完成后自动执行安全扫描，敏感明文、弱校验、越权漏洞全部拦截，禁止自动上传 Git；
4. 数据库新增表 / 字段必须配套隔离标识（项目 ID / 租户 ID），缺失则驳回生成；
5. 所有批量 AI 生产逻辑必须加限流、去重、风控拦截，无兜底批量代码禁止提交。
七、运维审计与日志安全规范
1. 日志分级：调试日志、业务日志、安全告警日志分开存储；
2. 权限变更、资金操作、违规 AI 生成、授权变更作为安全审计日志单独归档，不与调试日志、普通业务日志混存；
3. 安全审计日志按版本执行唯一留存周期：V1.0 本地版保留 90 天后自动清理；V2.0 私有化版至少保留 180 天，客户更高要求由部署配置覆盖；V3.0 SaaS 版永久归档；
4. 所有 AI 批量操作、人工高危操作日志标记操作主体（AI / 账号 ID）；
5. 私有化交付给客户的日志自动脱敏，我方核心机密不对外输出。
八、等保三级前置强制代码合规规范（全版本预埋、V3逐级增强）
本章节为等保2.0三级合规强制预埋标准，面向系统未来正式过等保做前置无重构预埋。所有代码开发、AI自动生成代码、版本迭代必须严格遵循。整体遵循规则：V1/V2 通用基础合规兜底、V3 全开三级强约束。所有合规能力仅增量叠加、不降级、不删除、不重构，适配全版本迭代体系。
说明：等保三级为公网商用SaaS系统强制测评标准，因此严苛的监管类、审计类、运维安全类规范仅 V3 生效；V1 本地、V2 私有化内网满足基础合规即可，无需强制落地三级严苛条款。
8.1 身份鉴别合规（等保必测）
全版本统一强制基础规则，AI生成代码默认适配：
1. 账号唯一标识：所有用户、子账号、管理员、代理账号必须拥有唯一不可重复ID，禁止匿名账号、通用共享账号。
2. 密码复杂度强制约束：系统新增账号、修改密码必须校验复杂度，支持长度、大小写字母、数字、特殊符号组合校验，禁止弱密码。
3. 会话安全管控：所有登录会话强制超时机制，闲置超时自动退出、销毁会话；支持单点登录冲突挤下线，防止账号多设备滥用。
4. 私有化/SaaS分级鉴权：V2私有化、V3云端必须支持多角色分级身份鉴别，最小权限分配，杜绝超权限账号存在。
5. 登录失败锁定机制（等保必测）：系统全版本强制启用登录风控锁定策略，连续多次密码错误自动锁定对应账号，支持自定义锁定时长；锁定期间禁止登录、禁止暴力重试，彻底防范账号暴力破解风险。
6. 管理员双因素认证2FA（等保三级核心项）【仅V3】：V3云端所有超级管理员、安全管理员、运维管理员后台登录，必须启用双因素认证，支持短信、邮箱、动态令牌任意两种组合校验；禁止核心高权限账号仅通过单密码登录，杜绝账号盗用、越权运维风险。
8.2 访问控制合规（等保核心红线）
1. 接口全鉴权强制：系统所有业务接口、后台接口、内部调用接口禁止无鉴权裸暴露，所有请求必须校验Token、权限、身份、租户归属，无任何接口例外（全版本强制执行）。
2. 横向越权彻底拦截：代码层强制校验数据归属关系，用户仅可操作本人、本项目、本租户数据，禁止查询/修改/删除他人数据，AI生成代码必须自带数据归属校验逻辑（全版本强制执行）。
3. 纵向权限隔离：普通用户、操作员、管理员、超级管理员、代理账号权限严格隔离，禁止低权限账号拥有高权限入口。
4. 权限动态管控：支持权限临时禁用、账号冻结、权限回收，所有权限变更实时生效、全程留痕。
5. 三员分立权限体系（等保三级强制模型）【仅V3】：V3云端系统严格拆分三类核心管理账号，权限完全互斥、独立隔离，满足等保三级正式测评要求：
1. 系统管理员：负责系统部署、配置维护、功能迭代，无日志审计、无安全风控权限；
2. 安全管理员：负责权限分配、风控配置、安全策略调整，无系统运维、数据修改权限；
3. 审计管理员：仅拥有安全日志、操作记录查询审计权限，无任何配置修改、数据操作、权限变更权限。
8.3 安全审计合规（满足等保日志要求）
1. 审计日志全覆盖：登录登出、权限变更、数据新增/修改/删除、资金操作、AI批量生产、违规操作、配置修改、授权变更，全部强制生成安全审计日志（全版本）。
2. 日志字段标准化：所有审计日志必须包含：操作人ID、操作时间、操作IP、设备信息、请求参数、操作结果、风险级别，字段缺失视为不合规。
3. 日志不可篡改：安全审计日志禁止业务代码修改、删除，仅支持查询归档，杜绝人为抹除操作记录。
4. 日志留存周期合规：严格遵循等保分级留存策略，V1本地日志留存90天、V2私有化日志留存180天、【仅V3】云端SaaS日志永久归档，满足监管备查要求。
8.4 入侵防范与代码安全合规
1. 防SQL注入强制：所有数据库查询、新增、更新逻辑，禁止字符串拼接SQL，统一使用参数化查询、预编译语句，AI生成SQL必须自动适配防护（全版本强制）。
2. 防XSS跨站攻击：前端传入参数、用户Prompt、自定义内容，代码层强制转义、过滤、校验，禁止恶意脚本入库、渲染。
3. 防重放攻击：所有敏感操作接口（支付、修改密码、删除数据、批量生产）强制时间戳+随机串校验，拦截重复请求、恶意重放。
4. 异常请求限流：单IP、单账号高频异常请求自动拦截，防止暴力破解、接口刷量、资源耗尽攻击。
5. 全站传输加密合规：系统所有环境（私有化、云端）强制启用HTTPS传输加密，禁止HTTP明文传输；所有后台管理接口、敏感业务接口、资金交易接口、用户隐私接口强制加密传输，杜绝数据传输窃听、篡改、劫持风险，全版本强制执行。
8.5 数据安全与脱敏等保合规
1. 敏感数据分类管控：手机号、实名信息、支付信息、授权密钥、商业Prompt、项目核心方案，全部定义为一级敏感数据，强制加密存储+传输加密。
2. 数据脱敏强制落地：敏感数据查询展示、导出、日志打印时自动脱敏，禁止完整明文展示、明文落地存储。
3. 数据最小化使用：业务逻辑仅获取必要字段，禁止查询、传输、存储非必要敏感字段，减少数据泄露风险。
4. 数据销毁合规：废弃数据、过期数据、注销账号数据，遵循等保销毁规范，逻辑软删除+加密销毁，杜绝残留泄露。
5. 数据备份与灾备恢复合规：建立全版本数据备份闭环机制，满足等保数据安全要求：
1. 自动定时备份：系统业务数据、配置数据、审计日志定时自动备份，支持增量+全量备份（全版本）；
2. 异地灾备【仅V3】：V3云端实现跨服务器异地备份，杜绝单节点数据丢失；
3. 恢复演练：定期开展数据恢复演练，留存演练记录，保障故障后可快速恢复业务数据；
4. 私有化版本支持本地备份导出、离线备份留存，保障客户数据资产安全。
6. 漏洞扫描与修复闭环合规【仅V3】：V3云端建立常态化安全漏洞管控机制，适配等保风险管控要求：
1. 定期漏洞扫描：周期性开展代码漏洞、接口漏洞、系统组件漏洞扫描；
2. 分级处置：高危漏洞立即修复、中低风险漏洞限期整改；
3. 闭环留存：所有漏洞扫描报告、修复记录、复查记录全程归档，形成完整风控闭环；
4. AI开发适配：AI自动生成代码后强制漏洞扫描，存在高危漏洞禁止提交上线。
8.6 软件容错与异常防护合规
1. 全接口异常兜底：所有接口、批量任务、AI生产逻辑必须完善异常捕获、容错处理，报错不泄露源码、不暴露服务器信息、不输出敏感路径。
2. 参数强校验：所有用户输入、外部传入参数，代码层强制类型、长度、格式、范围校验，非法参数直接拦截，禁止脏数据入库。
3. 服务熔断降级：高并发、异常流量场景支持熔断、降级、限流，避免系统崩溃、服务不可用，保障业务稳定性。
8.7 AI开发专属等保强制红线
1. AI自动生成的所有代码，必须默认预埋等保合规能力，禁止生成不符合等保规范的裸接口、裸逻辑。
2. AI迭代新增功能，必须同步补齐身份鉴别、访问控制、日志审计、数据脱敏能力，缺一不可。
3. AI禁止自动删除、简化、绕过任何等保合规代码，所有合规逻辑只增不减、永久兼容。
本章节为等保2.0三级合规强制预埋标准，为系统后续正式过等保免重构、免改造，所有代码开发、AI自动生成代码、迭代更新必须100%强制执行，适配V1/V2/V3全版本增量兼容，仅增量增强、不降级、不删除已有合规能力。本规范聚焦代码层、业务层、应用层等保硬性要求，数据层、架构网络层等保规则分别由数据库规范、架构接口规范承载，三者联动形成完整等保体系。
