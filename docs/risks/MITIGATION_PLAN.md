# 风险缓解计划

| 优先级 | 风险 | 当前状态 | 缓解动作 | 完成标准 |
|---|---|---|---|---|
| P0 | 跨租户、跨项目数据泄露 | 未验收 | 完整身份键、服务端授权、缓存与对象存储隔离 | 越权测试全部通过 |
| P0 | 任务重复执行或越过人工关口 | 未验收 | 幂等键、检查点、确认范围和影响范围 | 重启恢复测试通过 |
| P0 | 插件突破底座权限边界 | 未实现 | 清单校验、最小权限、签名和运行隔离 | 恶意插件测试通过 |
| P1 | 模型或外部服务长期无响应 | 未验收 | 有限超时、取消、熔断、降级和人工接管 | 不合作执行器测试通过 |
| P1 | 大媒体文件丢失或损坏 | 未验收 | 对象存储、校验和、版本账本、备份恢复 | 恢复演练通过 |
| P1 | 敏感信息进入日志或提示词 | 未验收 | 分级、脱敏、最小上下文和日志扫描 | 安全扫描通过 |

风险关闭必须附测试或演练证据，不能只修改状态文字。
