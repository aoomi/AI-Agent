# 威胁模型

## 保护对象

- 租户身份、用户资料、项目配置与长期记忆。
- 提示词、剧本、图片、视频、音频、字幕及导出成果。
- 模型凭据、插件授权、任务检查点和审计日志。

## 信任边界

浏览器、平台 API、任务执行器、模型供应商、插件进程、对象存储和运维入口相互视为独立边界。跨边界数据必须鉴权、校验、限流并保留审计证据。

## 主要威胁与控制

| 威胁 | 必须控制 |
|---|---|
| 身份伪造与越权 | 服务端校验完整身份键；客户端状态不作为授权依据 |
| 提示词或文件注入 | 文件类型、大小、内容和路径统一校验；模型工具使用白名单 |
| 跨项目记忆污染 | 项目事实、用户偏好、会话摘要分层存储并按作用域读取 |
| 任务重放与重复扣费 | 幂等键、状态机、检查点、原子计费和可追溯回滚 |
| 插件供应链攻击 | 签名、版本锁定、权限清单、隔离执行和禁用开关 |
| 敏感信息泄露 | 数据分级、最小日志、脱敏、加密和保留周期 |
| 媒体篡改或损坏 | 内容哈希、版本账本、不可变母版和恢复验证 |

上线前必须针对每个信任边界完成滥用用例、失败用例和越权用例测试。
