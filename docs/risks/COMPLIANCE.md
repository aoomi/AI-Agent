# 合规要求索引

本文件只维护合规要求到项目控制项的映射，不重复安全实现细则。安全基线以 [安全合规规范](安全合规规范.md) 为唯一来源。

| 范围 | 最低控制项 | 验收证据 |
|---|---|---|
| 身份与租户 | 所有请求携带稳定租户、用户、会话和作用域身份 | 鉴权测试、越权测试、审计日志 |
| 数据与隐私 | 数据分级、最小收集、用途限制、可删除与可导出 | 数据清单、删除记录、导出记录 |
| 模型与生成内容 | 模型来源可追溯，生成结果带必要 AI 标识 | 模型登记、任务档案、导出清单 |
| 插件与供应链 | 插件签名、权限声明、依赖锁定、漏洞扫描 | 签名记录、SBOM、扫描报告 |
| 私有化部署 | 客户数据不离开授权边界，离线授权可审计 | 部署清单、授权记录、审计导出 |
| SaaS 多租户 | 数据、缓存、任务、日志和对象存储均按租户隔离 | 隔离测试、恢复演练记录 |

具体适用法律、行业要求和数据地域由每次部署的合规评审确认；未经确认不得写成“已合规”。
