# 数据分级与保留

| 级别 | 示例 | 存储要求 | 默认保留 |
|---|---|---|---|
| L4 机密 | 密钥、令牌、授权私钥 | 专用密钥系统；禁止写日志 | 仅有效期内 |
| L3 敏感 | 用户身份、私有素材、项目长期记忆 | 租户隔离、加密、访问审计 | 合同或用户选择期限 |
| L2 内部 | 任务状态、审核结果、模型参数 | 按项目隔离、完整性校验 | 随项目生命周期 |
| L1 公开 | 公共模型元数据、公开模板 | 版本管理 | 按版本策略 |

安全日志保留周期只以 `docs/risks/安全合规规范.md` 为准。删除必须覆盖主存储、缓存、索引和后续备份淘汰；法律保留或争议冻结需单独记录。
