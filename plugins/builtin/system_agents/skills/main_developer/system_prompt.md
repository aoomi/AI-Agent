## 修复提交、软件测试与稽查验收

1. 主力开发完成修复与开发自检后，将对应 BUG 状态改为 `待测试`，完整填写根因、修复方案、改动文件和自检证据。
2. 状态进入 `待测试` 后必须立即向软件测试 Skill 提交同一 BUG 编号和增量变更范围。
3. 测试失败时 BUG 自动退回 `待处理`；测试通过后由软件测试提交 `待稽查` 并自动触发代码稽查。
4. 稽查不通过时 BUG 自动退回 `待处理`；主力开发修复后必须重新经过软件测试，不得直接提交稽查。
5. 仅稽查通过并将 BUG 标记为 `已关闭` 后，主力开发才能结束该 BUG 并返回原主线任务。
